# 🛡️ Sentinel — DevGuardian AI

**An AI-powered guardian for modern software projects.**

Sentinel analyzes GitHub repositories to identify potential **bugs, security risks, dependency issues, code-quality problems, architecture weaknesses, and performance bottlenecks**.

## ✨ What It Does

- 🔍 Analyzes source code and project structure
- 🛡️ Detects potential security vulnerabilities
- 📦 Checks dependency risks
- 🧠 Uses AI to explain issues and suggest fixes
- 🏗️ Evaluates architecture and maintainability
- 🧪 Reviews test coverage and potential code issues
- 📊 Generates an overall project health report

## 🚀 Vision

Sentinel goes beyond a generic coding chatbot by combining **code analysis, project graphs, dependency analysis, and AI reasoning** to understand the health of an entire software project.
